Session setup

Session values are configured in the bot host environment. This page never asks for or stores Facebook cookies.
  1. Set FB_COOKIES to the supported cookie string, or FB_APPSTATE to the exported session format.
  2. Set ECLIPSE_DASHBOARD_API_KEY to a long, random secret.
  3. Set ECLIPSE_DASHBOARD_ORIGIN to the exact dashboard origin.
  4. Restart the service and confirm Messenger session shows Connected.

Do not put Facebook cookies, API keys, or owner tokens in frontend code.
