Session setup

Paste your Facebook session in the panel below. It is held in server memory only; no persistent disk or encryption-key environment variable is needed.
  1. Paste a single-line cookie header or complete JSON appstate export.
  2. Choose Save session. The bot will attempt to connect immediately.
  3. If Render restarts, redeploys, or spins down, the session is cleared and you must paste it again.

Never share your Facebook session or put it in frontend code, screenshots, or public logs.
